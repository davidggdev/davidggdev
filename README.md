    Web application for writers focused on writing, planning and organizing novels, stories and fictional worlds.
    Built with Laravel, PHP, MySQL and JavaScript.
    Includes chapters, characters, locations, factions, notes, timelines, narrative events, worldbuilding and planning tools.
    Integration of optional local AI directly in the browser using WebGPU and WebLLM.
    Privacy-oriented architecture where AI analysis can run locally without sending the writer's text to an external backend.

    Browser extension for managing and tracking job applications directly from supported employment websites.
    Stores job offers, application statuses, notes, labels, reminders and professional profile data locally using IndexedDB.
    Includes local AI features with WebGPU/WebLLM to compare job offers with a professional profile, identify required skills and assist with interview preparation.
    Privacy-first architecture with no backend required for personal data storage.
